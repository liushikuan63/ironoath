# 界面主题美化计划

2026-10-14用户要求：抽时间优化现有界面，使其更加美观、符合游戏主题，列入计划。首个参照是商店月卡页截图，归档于 `tmp/ui-theme-plan-20261014-640477f5/shop-monthcard-user-reference.png`。本单元登记计划；核心对战、人机成长与性格互动继续优先推进。

## 视觉方向与现状

以《列王纪·铁誓》的中世纪城堡主题统一面板：深色铁饰和木色衬底承载操作区域，羊皮纸或浅色内容区承载权益说明，铜金点缀用于标题、选中标签和重要操作。优先复用现有 panel-iron、panel-parchment、panel-gilt、panel-kingdom 与 button-iron、button-chip 皮肤；先核实实际九宫格、边饰安全区和运行加载，避免装饰压住文字。

参照截图可见：权益、领取状态和到期信息层级不清；卡片内部留白较多，正文与按钮分散；灰色状态与时间说明可读性弱；绿色购买按钮与其余深色按钮材质不一致。优化应提高阅读和操作效率，不能只换底色或加纹理。截图顶部被截取的部分不作为完整页面裁切缺陷结论。

## 实施顺序

| 阶段 | 范围与生产入口 | 具体结果 | 前置与边界 |
| --- | --- | --- | --- |
| UI-01 商店与月卡 | ShopPanelView.ts、game/shop/ShopPanel.ts | 统一币种页签及选中状态；月卡名称和价格/期限组成清晰标题区；购买即得、每日权益组成紧凑权益区；领取状态与下次刷新放在操作附近；到期信息作为次级说明；主次按钮统一材质和状态；保留上下卡入口 | 当前核心玩法单元收口后安排；复用实际下发价格、奖励、时间与可领状态，不静态抄配置；不改购买/补领/期限规则 |
| UI-02 活动与任务 | QuestPanelView.ts、game/activity/ActivityPanel.ts、game/quest/QuestPanel.ts | 复用标题、奖励条、进度/状态、主操作和说明的视觉层级；统一行高、间距和对齐；明确可领取、进行中、已完成、已过期的可读状态 | 商店视觉验收通过后推进；保留分页、手领和原有可见内容，防止增加装饰后挤掉已有操作 |
| UI-03 共享面板统一 | PanelNav.ts及受影响的共用组件 | 将已验证的字体层级、内容安全区、页签、按钮与禁用状态整理到现有共用样式入口；逐步应用于其他面板 | 先确认当前样式和资产生产调用，不另建竞争样式体系；不把所有面板同时重写 |

## 每阶段验收条件

1. 先留当前真实运行图，再用新产物在手机窄屏、常见竖屏与宽屏查看结果，核对长名称、多奖励、临近到期和较长说明；内容不叠字、不越框，边饰不遮标题和按钮。
2. 优先级清楚：一眼能找到权益、当前状态与主要操作；主按钮、次按钮、禁用按钮和选中页签风格一致，状态不只依赖颜色。图标和纹理不降低文字对比度。
3. 操作区域便于触控；检查键盘/焦点和已有交互支持；加载、失败、购买确认、可领、已领、过期和补领状态与服务端一致。禁止把内部ID或枚举露给玩家。
4. 实际点通页签、上下卡、奖励领取和既有确认流程；用自有测试账号/候选后端验证，不进行真实付款或清空原账号。保留截图、控制台错误数量、输入产物SHA与量具结果。
5. 每阶段按改动执行客户端测试、类型检查、静态门、构建和受影响真实探针。月卡、活动和任务验证分别覆盖对应生产链；修改共享导航、行序或新增入口时，批跑相关探针并包含 social-permission、social-create、rank 的已有内容可见性族。单张截图或仅编译通过不作为交互验收完成。

## 当前未做

本次只登记范围、顺序、资源复用与验收标准，尚未更改界面代码、替换运行资产或进行新界面的视觉验收。具体排版尺寸与素材适配在每阶段读取实际布局和运行图后确定，不把截图比例当作所有设备尺寸。核心主线下一项仍是有对象的人机挑衅回应与主动挑衅，以及人机对真人的实际对战闭环。

## 持续目标与执行起点（2026-10-14）

用户已要求设定目标并持续完成三个阶段，现在按UI-01、UI-02、UI-03顺序实施。每阶段完成界面、真实多视口/状态/交互验收、留档和本地提交后进入下一阶段；原核心主线保留。用户进一步要求三个阶段之后把其他可推进待完成项列入持续目标，届时先核队列与需求依据，优先接回核心对战、人机有对象挑衅/回复及双向对战；需要产品裁决的规则保持待裁决，不替用户编数值。

UI-01具体实现：保持现有240/184两种逻辑高度和节点名、卡片页容量、价格/奖励与支付领取流程；月卡采用现有gilt九宫格底板，并按其实际24px框带留文字安全区，压实权益/状态/期限行；普通货架与页签/按钮复用当前薄边iron/chip材质。只改展示层，先真实运行截图和月卡/兑换交互，失败回执与刷新也必须过。共用样式统一在UI-03做，不另建竞争体系。
