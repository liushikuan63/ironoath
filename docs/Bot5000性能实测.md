## 原因与最小改动

旧均值路径先读取/复制全部城主的 PlayerSave，之后才剔除 Bot；5000 Bot 会重复搬运大量与真人均值无关的档。第一修复先筛真人再读玩家档，均值公式、缺档忽略和读后身份复核保留，不缓存均值。第一候选冷轮仍需约 42 秒、单 tick P99 仍约 7.5～7.8 毫秒，不能写成达标。

第二个热点是身份判定反复调用完整画像 all()，包含全量排序/解码。增加 BotProfileStore.existingIds：内存直接按输入键 containsKey；Mongo 使用 _id $in 并只投影 _id。Registry 继续保留输入顺序、重复项和 null 过滤，存储故障向外传播，不降级为真人；跨实例登记/删除仍读取权威存储。

## 持久化测量与单驱动均值作用域（2026-10-14 续项）
